# Global-Map-of-Folklore
In this project, I developed a web that collects folfloristic narratives (e.g. urban legends) and displays the locations these stories probably orginated or was distributed to. In addition to the search and filter functions, the web also includes features for performing NLP analysis: identifying most frequent words; named entity recognition (NER); matching stories that share similar narratives (sentence embeddings).  

You can visit the website here: [Global Map of Folklore](https://thisiswuq.github.io/Global-Map-of-Folklore.github.io/Project-Map-of-Folklore)
